# Implementation Plan: Altitude Display

**Branch**: `001-altitude-display` | **Date**: 2026-10-27 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `/specs/001-altitude-display/spec.md`

## Summary

A single-purpose Flutter app: an in-app splash screen showing an image for about 2 seconds, then
one main screen that streams the phone's GPS altitude and shows it in feet. Location access is
isolated behind a small interface so the UI and state logic are unit-testable with fakes. Code is
written and tested on Windows (VS Code); the repo is then cloned to a MacInCloud machine for the
Xcode build, signing, and device run.

## Environments

The app is **Flutter/Dart only**. No hand-written Swift/Objective-C; the only native-side edits
are configuration (Info.plist, signing, bundle ID). Work is split by environment:

| Environment | Work |
|-------------|------|
| **Windows / VS Code** | Flutter SDK setup, `flutter create --platforms=ios`, all Dart code, assets, `pubspec.yaml`, Info.plist usage string and portrait lock (text edits), unit/widget tests, `flutter analyze`, commits and push |
| **MacInCloud / Xcode** | `git pull`, `flutter pub get`, `pod install`, signing team and bundle ID in Xcode, simulator run, physical iPhone run and GPS validation, commit `Podfile.lock` and Xcode project changes |

Rules: everything that can be done on Windows MUST be done there; Mac sessions are kept short and
limited to build, signing, and device validation. Git is the only hand-off between environments.

## Technical Context

**Language/Version**: Dart 3.x (null safety) on the Flutter stable channel

**Primary Dependencies**: `geolocator` (location stream, permission, service status); no state
management package (built-in `StreamBuilder`)

**Storage**: N/A (no location data persisted; constitution III)

**Testing**: `flutter_test` (unit + widget tests) with a fake location service; `flutter_lints`

**Target Platform**: iOS 13+ (iPhone), portrait only. Developed on Windows; built on macOS
(MacInCloud) with Xcode

**Project Type**: mobile-app

**Performance Goals**: altitude visible within 10 s of launch with a fix; splash 2 s; UI updates
at the location stream rate

**Constraints**: foreground, while-in-use location only; no network; no background modes

**Scale/Scope**: 2 screens (splash, main), 1 service interface, ~6 source files
